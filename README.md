# tinykit

A throwaway demo target for the [`orchestrate` and `executor` skills](https://github.com/feniix/agent-orchestration). The code and the tickets are invented so a recorded run has something real to do.

`skills/` is a copy of those skills at commit `2639954`, installed here and nowhere else.

## Functions

- `clamp(value, min, max)`
- `formatBytes(count)`
- `parseDuration(text)`
- `slugify(text)`
